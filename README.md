# RapiUang

Aplikasi web sederhana untuk mencatat pengeluaran harian dan memantau anggaran.

## Fitur

- Atur anggaran untuk tiap tanggal.
- Tambah, ubah, dan hapus catatan pengeluaran.
- Kelompokkan transaksi berdasarkan kategori.
- Lihat total pengeluaran dan sisa anggaran.
- Simpan data di browser menggunakan `localStorage`.

## Menjalankan secara lokal

Buka `index.html` langsung di browser, atau simpan folder ini di dalam `htdocs` dan buka melalui XAMPP.

## Mengaktifkan GitHub Pages

1. Buka **Settings → Pages** pada repository GitHub.
2. Pada **Build and deployment**, pilih **Deploy from a branch**.
3. Pilih branch `main` dan folder `/(root)`, lalu tekan **Save**.
4. Setelah proses penerbitan selesai, situs akan tersedia di `https://beng-prog999.github.io/rapiuang/`.

Data pengeluaran hanya tersimpan di browser pada perangkat yang digunakan. Data tersebut tidak diunggah ke repository atau dibagikan antarperangkat.
